# Laravel for front-end developers

A VitePress tutorial that continues after the [PHP tutorial for FE devs](/lab/php-tutorial-for-fe-devs/) - notes-style, practical, aimed at people who already know JS/TS and modern PHP.

Written like [lukaszkups.net/notes](https://lukaszkups.net/notes/).

## Run the docs

```bash
npm install
npm run docs:dev
```

Build / preview:

```bash
npm run docs:build
npm run docs:preview
```

## Assumptions

You've already gone through the [PHP tutorial for FE devs](/lab/php-tutorial-for-fe-devs/) (Composer, PSR-4, request lifecycle, PDO, sessions, CSRF, mini-router). This picks up from there and maps it onto Laravel.
